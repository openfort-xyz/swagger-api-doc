# Openfort API documentation

[Swagger UI](https://github.com/swagger-api/swagger-ui) hosted on GitHub Pages at
[https://openfort-xyz.github.io/swagger-api-doc/](https://openfort-xyz.github.io/swagger-api-doc/).

The OpenAPI specification is loaded live from
[https://api.openfort.io/api-docs/openapi.json](https://api.openfort.io/api-docs/openapi.json),
so the documentation always reflects the deployed API — there is no spec file to
update in this repository. The served spec is generated by the API server
(see `src/lib/openapi/mergedOpenApiSpec.ts` in the `api` repository).

## How it works

- `index.html` + `dist/` — the Swagger UI, based on
  [peter-evans/swagger-github-pages](https://github.com/peter-evans/swagger-github-pages).
- `dist/swagger-initializer.js` — points the UI at the live spec URL.
- [`update-swagger.yml`](.github/workflows/update-swagger.yml) — daily workflow
  that opens a PR when a new Swagger UI release is available.

## Run locally

```bash
npx serve .
```
